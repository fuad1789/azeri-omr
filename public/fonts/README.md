# Font Installation Instructions

## Noto Sans Font Setup

Azərbaycan hərflərinin (ə, ş, ı, ö, ü və s.) düzgün görünməsi üçün Noto Sans fontunu yükləməlisiniz.

### Addım 1: Fontu yükləyin
1. Bu linkə daxil olun: https://fonts.google.com/noto/specimen/Noto+Sans
2. "Download family" düyməsinə basın
3. ZIP faylını açın

### Addım 2: Fontu yerləşdirin
1. ZIP-dən `NotoSans-Regular.ttf` faylını tapın
2. Bu faylı `public/fonts/` qovluğuna kopyalayın
3. Faylın yolu belə olmalıdır: `public/fonts/NotoSans-Regular.ttf`

### Alternativ: Birbaşa yükləmə
Aşağıdakı linkdən birbaşa yükləyə bilərsiniz:
https://github.com/google/fonts/raw/main/ofl/notosans/NotoSans-Regular.ttf

Faylı `public/fonts/NotoSans-Regular.ttf` adı ilə saxlayın.

### Qeyd
Əgər font yüklənməsə, sistem avtomatik olaraq Helvetica fontunu istifadə edəcək, amma Azərbaycan hərfləri düzgün görünməyə bilər.
